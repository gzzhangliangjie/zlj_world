# 体素管线颜色值范围规范(2026-10-06 固化)

> 同一类错误连犯 4-5 次,用户要求固化。**任何体素/贴图管线动颜色前必读本文档。**
> 适用:Tools/glb_to_vox.py、Tools/glb_to_geo.py、batch_vox.py、batch_bbmodel.py、vox_to_bbmodel.py、r96_bones.py 及一切新写的颜色处理代码。

## 核心规则

### 1. 颜色只有一种内部标准:**0-255 整数三元组**

管线内所有中间表示统一 `(r,g,b)` 0-255 int。其他范围进来,入口处一次归一,出口处一律 `np.clip(v,0,255)`。

### 2. 输入侧按来源分三种,判据固定

| 来源 | 实际范围 | 归一化 |
|---|---|---|
| glTF `baseColorFactor` (trimesh 读出) | **可能 0-1 浮点,也可能 0-255 字节值**(实测 Taurus GLB 读出 `[215,168,107]`) | `if max(b3)>1.001: 已是字节` else `×255`。禁止盲乘 255 |
| glTF `COLOR_0` 顶点色 / trimesh `vertex_colors` | 0-1 浮点(归一化 uint8) | ×255 |
| PIL / RGBA 贴图 | 0-255 | 直用 |
| MagicaVoxel `.vox` RGBA chunk | 0-255 | 直用 |

**判据固定:`max(component) > 1.001` ⇒ 字节值,否则浮点。** 因为 0-255 整数里的 1、2、3 这类小值不存在歧义损失(浮点色极少有分量 ≤0.004 的非黑非边界色),而歧义只发生在纯黑(0,0,0):字节黑=(0,0,0),浮点黑=(0,0,0),两者归一后都是 (0,0,0),无歧义。

### 3. 写出侧全量 clip

```python
col = (int(np.clip(round(r),0,255)), int(np.clip(round(g),0,255)), int(np.clip(round(b),0,255)))
```

适用:body 贴图色、palette 写入、geo/vox 写出、REMAP 表目标值、任何乘加提亮之后。

### 4. uv 压 1 像素中心(防渗色)

调色板贴图逐面 UV 必须压到色块像素中心,禁止整面贴:

```python
u = (slot % 16) + 0.5
v = (slot // 16) + 0.5
```

历史事故:UV 整面 → 相邻色块渗色,方块边界出现杂色。

### 5. 展示提亮表(REMAP,仅限"展示用"资产)

| 用途 | 值 |
|---|---|
| 近黑提亮 | `#030303 → #26262b` |
| 轮子统一色 | `(52,58,64)` 即 `#343a40` |
| bcf 缺省回退 | `(0.59,0.提亮后 150,150)` → 0-255 后 `(150,150,155)` |

游戏资产不做 REMAP(游戏内光照自会提亮),展示/截图才用。

### 6. 单色故障排查树(colors=1)

```
colors=1
 ├─ 全白 255,255,255 → bcf 字节值被盲乘 255(本规范 §2;2026-10-06 Taurus 全白事故)
 ├─ 全灰 (150,150,155) → bcf=None 回退默认灰:查 trimesh 是否读到 material(PBR vs unlit)、查 primitive.material 索引
 ├─ 全黑 → 顶点色 0-1 浮点没乘 255;或 bcf 0-1 被当字节直用
 ├─ 单色但"应为多色" → 源模全节点共用一材质(poly.pizza 常见);对策=轮名节点强制色(52,58,64)或连通域拆分
 └─ 颜色块边界杂色 → UV 渗色(§4)
```

### 7. 展示图亮度

渲染截图统一 `ImageEnhance.Brightness(1.12)`,仅用于交付图,不影响资产数据。

## 历史事故账(为何固化)

1. **2026-09 黑白灰壳**(glb_to_geo 早期):顶点色缺失回退白、材质色缺失回退灰、BFS 扩散污染 → 单色壳。
2. **2026-10-05 越界值**:bcf ×255 无 clip,int() 溢出截断,深色块出杂色。
3. **2026-10-06 全白事故**(c793aec 修复):trimesh 读 Taurus bcf=`[215,168,107]`(字节值),代码盲乘 255 → 全部钳 255 → 七款模型一水白。用户原话:"颜色太单一了"。
4. **UV 渗色**:整面 UV 贴 16×16 调色板,方块边缘吸到邻色。
5. **单色糊轮**:源模共用白材质,轮车同色不可辨 → 轮名强制色。
6. ledger:每次颜色事故必须记一条到本文档(日期+症状+根因)。

## 快速自检脚本(管线改色后必跑)

```python
from collections import Counter
nodes = load_nodes(x.glb)
print(Counter(p['c'] for p in nodes).most_common(8))   # 期待:≥3 色、无 (255,255,255) 全白一色独占
```
